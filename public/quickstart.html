Get started in 60 seconds

From zero to your first career AI response in under a minute.

1

Get your free API key

Register with your email. No credit card needed. Key generated instantly — 1,000 free requests every day, permanently.

2

Install the SDK

npm
npm install careerlm
pip
pip install careerlm
💡 Or use the REST API directly — no SDK needed. All examples show both.
3

Score your first CV

JavaScript
const { CareerLM } = require('careerlm')
const client = new CareerLM('csk_free_v1_YOUR_KEY')

const score = await client.cv.score(
  'Ada Okonkwo\nSenior Python Developer\nPaystack 2021-2024...',
  'We are hiring a Senior Python Engineer...'
)

console.log(score.ats_score)               // 87
console.log(score.grade)                  // "B+"
console.log(score.keyword_match.missing)  // ["Kubernetes"]
console.log(score.top_suggestions[0])    // "Add Kubernetes to skills section"
cURL
curl -X POST http://localhost:3005/v1/career/cv/score \
  -H "X-Api-Key: csk_free_v1_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"cv_text":"Ada Okonkwo...","job_description":"..."}'
✅ Free tier supports CV scoring with careerlm-flash (cs-haiku)
4

Benchmark salary (196 countries)

JavaScript
const salary = await client.salary.benchmark('Data Engineer', 'NG', {
  city:             'Lagos',
  years_experience: 4,
  skills:           ['Python', 'SQL', 'dbt'],
  options: { currency: 'NGN' }
})
console.log(salary.salary_range.median)     // 6800000
console.log(salary.negotiation_target)       // 7500000
console.log(salary.skill_premiums)           // [{ skill: "dbt", premium_percent: 12 }]
💡 Salary benchmarking requires Starter tier (£19/month). See pricing →
5

Generate a cover letter (15 modes)

JavaScript
const letter = await client.coverLetter.generate(cvText, jobDesc, {
  mode:         5,          // Company-specific research hook
  company_name: 'Paystack',
  tone:         'confident',
  options: { word_limit: 280 }
})
console.log(letter.content)   // Full cover letter text
console.log(letter.mode_name) // "Company-specific"

Available modes: Achievement-led, Insight-led, Problem-solution, Narrative, Company-specific, Question-led, Bold statement, Data-driven, Cultural fit, Career transition, Promotion, Referral, Remote, Multilingual, Executive.
