Changelog

Version history for CareerStudioMax Developer Cloud, the purpose-built career intelligence API.

Key lifecycle, request IDs, and Idempotency-Key

2026-08-28

Revoking a key now removes it from your active key list immediately; calling delete on an already-revoked key permanently removes it, and revoked keys you never delete are cleaned up automatically after 90 days. Every response now carries an X-Request-Id header, rate-limit and quota errors carry an explicit retryable field, and POST /register supports an Idempotency-Key header. The OpenAPI spec — present in this repo since launch but never actually served — is now reachable at /openapi.yaml.

Admin visibility for new signups

2026-08-24

New Developer Cloud accounts now generate a real-time admin alert and appear in the shared cross-platform audit log, matching what CAMP/CSTM-2/Transformer/CSVM already had.

Endpoint audit, context wiring fixes

2026-08-22

A real endpoint audit script added; context_id/target_country now correctly flow into the scoring endpoints that were silently ignoring them.

CQL (CareerStudio Query Language) — Phase 1

2026-08-20

A minimal, pipe-based query DSL over /v1/career/* launched at /v1/cql.

Fixed: unparseable model output on schema-requesting endpoints

2026-08-19

/cv/score and every other endpoint that requests structured JSON could return an unparseable, reasoning-prefixed string as if it were clean JSON. Fixed at the source.

CareerStudioMax Developer Cloud launches

2026-08-18

The first release: 9 purpose-built career intelligence endpoints — CV scoring, optimisation, salary benchmarking, cover letters, job matching, interview prep, skill gap analysis, chat completions, and persistent career context.
